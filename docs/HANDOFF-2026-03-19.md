## Execution Standard

The Ellen & Danny friction card IS the floor. Every output matches that specificity:
- Meet the leader at the moment of frustration
- Trace it to the data
- Hand them the prescription
- No templates. No data display. Leader clarity.

If two people receive the same sentence, the output is wrong.

## Key Decisions Made

1. **lwyl-app is the base** — not the redesign. The redesign's features (Bridge, Agreements, SOP Engine) were ported IN.
2. **Each client is an org** — not a team under one org. Data isolation is per-org.
3. **Daniel is the only user logging in for now** — leaders see the app via screen share during live calls.
4. **Assessment data comes from Innermetrix link or PDF upload** — no manual name entry.
5. **SOP Engine uses real 3Ps content** — sourced from Daniel's consulting methodology doc, not generated templates.
6. **Friction Map content engine is untouched** — it already meets the execution standard. Only the visual design was upgraded.
